## 📌 About This Project

**LocksmithCallFlow™** is a high-performance, single-file landing page for a locksmith lead generation agency. It presents a complete inbound job acquisition system built around Google Map Pack domination, high-intent emergency call ads, and automated missed-call recovery — helping locksmith businesses across Canada, USA, and UK make their phone ring first, with direct calls that don't pass through aggregator platforms that resell the same lead to multiple competitors.

## 🚀 Deployment

### Option 1 — GitHub Pages (Free, No Server Needed)

```bash
# 1. Clone the repo
git clone https://github.com/your-username/locksmithcallflow.git
cd locksmithcallflow

# 2. Add your profile photo
# Name it profile-img.png and place it in the root folder

# 3. Push to GitHub
git add .
git commit -m "Initial deploy"
git push origin main
```

Then: GitHub repo → **Settings** → **Pages** → Source: `main` branch → **Save**

🌐 Live at: `https://your-username.github.io/locksmithcallflow`

---

### Option 2 — Netlify (Drag & Drop, 60 Seconds)

1. Go to [netlify.com](https://netlify.com) → Log in
2. **"Add new site"** → **"Deploy manually"**
3. Drag your project folder (containing `index.html` + `profile-img.png`) into the upload zone
4. ✅ Instant live URL — free custom subdomain included
